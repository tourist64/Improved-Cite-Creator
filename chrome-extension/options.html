Cite Creator Settings

Instructions

When enabled, Cite Creator automatically computes a cite for the current page and shows it in a small box on the page. Default PC shortcuts use Alt, default Mac shortcuts use Option.

ctrl+alt+c - Copy the current cite, optionally including any selected text, e.g. card text.

The letter grade on each cite is a rough measure of how confident you should be in its accuracy. It's based on where each field came from: the page's structured data (JSON-LD or microdata) scores highest, meta tags next, a guess from the page's byline markup lowest - and anything you set yourself counts as certain.

Cite Creator is designed to produce cites for US high school and college debate. It works best on major news sites, and doesn't work inside PDFs.

Custom formats replace the codes between %'s, but retain all other text and whitespace. You can use the following codes:

%author%Author's full name
%first%Author's first name
%last%Author's last name (or the publication, if there's no individual author)
%quals%Author qualifications, if any
%date%Full date
%y%1 or 2 digit year
%title%Article title
%publication%Publication
%url%Full URL
%accessed%Today's date
%linebreak%Add a line break

Keyboard Shortcuts

Custom keyboard shortcuts must be a single string (no spaces), e.g. ctrl+alt+c or command+option+1 or f2. Some shortcuts may conflict with built-in browser shortcuts or other extensions, so only change these if you know what you're doing. Changes require reloading the current page.
